# Live-Project-Unity
## Indroduction
&emsp;During this live project I made a clone of the game Vampire Survivors that will be added to a larger project that includes other games made by other students of [The Tech Academy](https://www.learncodinganywhere.com). Throughout the project we implemented Agile/Scrum practices such as daily standups and using user stories as the checkpoints to track out progress and complete aspects of the game one at a time. I started the project with a basic comprehension of C# and Unity and had to learn more as problems needed solving and more functionality needed to be added. I plan on adding more to this game in my free time as I had a lot of fun making this game but I am happy with where I ended up during these 2 weeks.
